## 1. 报错代码与快速诊断表

| 常见报错提示 | 可能原因 | 解决动作 |
| :--- | :--- | :--- |
| `certificate has expired or not yet valid` | 本地时间与标准北京时间不同步 | 校准 Windows/Mac 系统时钟 |
| `connect: connection refused (127.0.0.1:7890)` | 代理软件内核崩溃或端口被占用 | 重启客户端或修改 Mixed Port 为 7891 |
| `i/o timeout` / `context deadline exceeded` | 本地 ISP 运营商干扰或节点临时维护 | 切换至备份 BGP 专线节点或刷新订阅 |
| `DNS Leak / 无法解析主机名` | 本地 DNS 污染未被代理接管 | 开启 Clash Verge 的 TUN 模式或启用安全 DNS |

## 2. 深度排查一：本地系统时间误差（TLS 证书握手失败）

现代加密协议（VLESS、Trojan、Hysteria2、Shadowsocks）依赖 TLS 证书时间校验。如果您的电脑或手机时间比标准时间**快或慢超过 60 秒**，服务器会直接拒绝握手。

- **Windows 用户**：
  1. 按 `Win + I` 打开「设置」->「时间和语言」->「日期和时间」；
  2. 确保勾选 **「自动设置时间」**；
  3. 点击 **「立即同步」** 按钮。
- **macOS 用户**：
  1. 打开「系统设置」->「通用」->「日期与时间」；
  2. 启用「自动设置日期和时间」。

## 3. 深度排查二：本地端口冲突（7890 / 10808）

如果在启动客户端时提示 `bind: address already in use`：
1. 检查后台是否同时运行了多个代理客户端（如同时开了 Clash 和 v2rayN）；
2. 彻底退出其中一个软件，或在客户端设置中将 `Mixed Port`（混合端口）改为任意空闲端口（例如 `17890` 或 `27890`）。

---

## 4. 深度排查三：订阅链接拉取失败或更新为空

- 确认当前处于可直连网络（无需开旧代理），访问 [NanoCloud 官网入口](https://nano-cloud.store/) 测试连通性；
- 若浏览器能打开官网但客户端拉取超时，可将订阅链接在浏览器地址栏打开，若能正常下载 Base64/YAML 文件，则说明是客户端的 SSL 校验限制，在客户端关闭 `Strict SSL` 即可。

---

## 5. 深度排查四：ChatGPT / OpenAI 访问显示 1020 / Access Denied

OpenAI 对机房 IP 与节点出口有较严格的风控：
1. 请勿频繁在短时间内切换国家地区节点；
2. 在客户端选择带有 `ChatGPT/Claude 解锁` 标记的原生 IP 节点（推荐美国、日本、新加坡优质专线）；
3. 清理浏览器对应站点的 Cookies 缓存，或使用浏览器隐私模式重试。

---

## 6. 深度排查五：无法访问 Telegram 桌面端或移动端

Telegram 默认不自动跟随系统代理：
- 在 Telegram 桌面端中，点击左上角「设置」->「高级」->「连接类型」；
- 添加代理类型为 `SOCKS5` 或 `HTTP`，服务器填写 `127.0.0.1`，端口填写客户端对应的本地端口（例如 `7890`）。
