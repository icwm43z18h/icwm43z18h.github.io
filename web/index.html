HELP & RESOLUTION

常见问题与排错手册

遇到疑问或网络异常？查阅以下高频问答，95% 的问题即可迎刃而解。

为什么我连接节点后显示 TLS 握手失败或全部超时？ +
绝大多数 TLS 握手报错是由于您设备本地的系统时间与标准北京时间偏差超过了 60 秒。由于现代加密协议对时间敏感，请打开 Windows 或手机系统设置，开启「自动时间同步」并点击立即同步，随后重新连接即可恢复正常。
订阅导入客户端时提示 403 / 500 / Network Error？ +
请确保在拉取订阅时未开启其他已失效的旧代理软件造成流量闭环。您可先彻底退出第三方加速工具，直接在浏览器中访问官网控制台确认订阅链接是否最新；若客户端支持跳过证书检查，可在对应配置中开启该选项后重试。
访问国内网站（微信、百度、淘宝）变慢或被拦截？ +
请检查客户端的路由分流模式。若误选为「Global / 全局代理」，所有流量均会绕经境外节点。请将客户端切换为「Rule / 规则分流」或「配置模式」，国内流量将自动直连，不消耗套餐流量，速度最快。
支持多个设备同时使用同一个账号吗？ +
完全支持！猎户座套餐支持 2 台设备，白羊座套餐支持 5 台设备，射手座套餐支持多达 10 台设备同时在线。您可以自由在手机、电脑、平板和路由器上配置同一个订阅。
