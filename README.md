## 💻 全平台客户端推荐与一键配置

NanoCloud 深度支持全系统桌面与移动端环境，推荐使用现代轻量级客户端：

### 1. Windows 用户
- **推荐工具**：[Clash Verge Rev](https://nano-cloud.store/client/)（现代开源 Tauri 架构，资源占用低） / [v2rayN](https://nano-cloud.store/client/) / [Sing-box](https://nano-cloud.store/client/)
- **配置步骤**：打开客户端 -> 复制 NanoCloud 订阅链接 -> 点击「从剪贴板导入/新建配置」-> 启用 TUN 模式或系统代理 -> 选择 `自动优选` 策略组。
- **进阶文档**：详见 [Clash Verge Rev 进阶配置指南](./docs/clash-verge-guide.md)。

### 2. macOS 苹果电脑用户
- **推荐工具**：[Clash Verge Rev for Mac](https://nano-cloud.store/client/)（支持 Apple M 系列芯片与 Intel） / [Surge](https://nssurge.com/) / [Loon for Mac](https://nano-cloud.store/client/)
- **配置步骤**：下载 `.dmg` 文件拖入应用程序，导入订阅后授权允许系统代理权限即可。

### 3. iOS 苹果手机/平板
- **推荐工具**：[Shadowrocket (小火箭)](./docs/shadowrocket-ios-setup.md) / [Quantumult X](https://nano-cloud.store/client/) / [Loon](https://nano-cloud.store/client/) / [Sing-box](https://nano-cloud.store/client/)
- **配置步骤**：使用美区/港区 Apple ID 下载客户端，在 Safari 中打开 [NanoCloud 客户端中心](https://nano-cloud.store/client/) 点击「一键导入到 Shadowrocket」。

### 4. Android 安卓手机/电视盒子
- **推荐工具**：[Clash Meta for Android](https://nano-cloud.store/client/) / [Surfboard (冲浪板)](https://nano-cloud.store/client/) / [v2rayNG](https://nano-cloud.store/client/)
- **配置步骤**：安装 `.apk` 包后，在配置界面点击右上角「+」，选择 URL 导入订阅地址，点击连接。

### 5. Linux / 软路由 OpenWrt
- 支持通过 `mihomo` / `sing-box` 命令行核心或 `ShellCrash` / `OpenClash` 进行家庭网络与局域网全局加速。

## 🛠️ 高频使用问题与快速排障

### Q1: 订阅更新提示 `Network Error` 或 `403/500` 错误？
- **解决方案**：请先检查当前电脑是否开启了失效的旧代理软件造成死循环。先退出第三方代理，使用浏览器直接访问 [NanoCloud 官网](https://nano-cloud.store/) 获取最新动态订阅链接。

### Q2: 节点全部超时 (Timeout) 或提示 TLS 握手失败？
- **核心原因**：90% 的情况是**本地电脑或手机的系统时钟与标准时间存在偏差**（超过 60 秒即会导致加密证书握手被拒）。
- **解决动作**：进入系统设置，开启「自动时间同步」并点击「立即同步」，重启客户端即可恢复。

### Q3: 为什么微信、淘宝国内网页变慢了？
- **解决方案**：检查客户端的路由分流模式是否被误设为了 `Global / 全局模式`。请务必将分流策略调整为 **`Rule / 规则分流`** 或 **`配置模式`**，即可保障国内直连不走代理、海外流量自动加速。

> 更多排错方案请参阅完整版 [故障排查与 FAQ 实战指南](./docs/troubleshooting-faq.md)。
